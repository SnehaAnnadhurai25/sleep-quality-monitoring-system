Sleep Quality Monitoring System

An IoT-based system that monitors heart rate, oxygen saturation and body movement using physiological sensors, with real-time data visualization and alert functionality through Arduino Cloud.

▶ Watch Demo Explore Working ↓

IoT Monitoring Prototype

ESP32 · MAX30100 · ADXL335 · Arduino Cloud

Project Overview

Monitoring physiological activity through IoT

The system integrates heartbeat and motion sensors with an ESP32 microcontroller to monitor physiological parameters. Sensor data is transmitted to Arduino Cloud, allowing users to remotely view heartbeat, SpO₂ and movement information through a mobile interface. A buzzer provides an audible alert when movement is detected according to the programmed condition.

🎯

Project Objective

To monitor heart rate, oxygen saturation and body movement during sleep using sensor technology and IoT connectivity, while providing accessible monitoring and alert mechanisms.

💡

Proposed Solution

The MAX30100 sensor measures heart rate and SpO₂ through fingertip sensing, while the ADXL335 detects body movement. ESP32 processes the sensor information and transmits the data to Arduino Cloud.

📱

Remote Monitoring

Arduino Cloud enables users to monitor heart rate, SpO₂ and movement information through a mobile phone, providing convenient access to the collected data.

🔔

Alert Mechanism

When movement is detected according to the system's programmed condition, a buzzer produces an audible alert. The configured cloud alert system can also notify the user through the connected mobile interface.

System Workflow

How the System Works

The system continuously collects sensor information, processes it through ESP32, and enables remote monitoring through Arduino Cloud.

01

Sensor Data Collection

MAX30100 measures heart rate and SpO₂ through fingertip sensing. ADXL335 detects body movement.

02

ESP32 Processing

ESP32 receives sensor measurements and processes the collected data according to the programmed logic.

03

Cloud Communication

Sensor information is transmitted through Wi-Fi to Arduino Cloud for remote monitoring.

04

Mobile Monitoring

Heart rate, SpO₂ and movement data can be viewed through the Arduino Cloud mobile interface.

Alert & Notification System

Local and Remote Alerts

The system provides an alert mechanism through the hardware and cloud platform to support convenient monitoring.

🔊

Audible Buzzer Alert

When body movement is detected according to the programmed condition, the buzzer generates an audible alert, providing immediate feedback from the hardware system.

📲

Arduino Cloud Notification

Sensor data is transmitted to Arduino Cloud. Users can monitor heartbeat, SpO₂ and movement information through the connected mobile interface and receive configured notifications.
